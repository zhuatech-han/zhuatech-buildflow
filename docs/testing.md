格式与静态检查：backend `mvn spotless:check`；frontend `npm run format:check`、`npm run lint`。后端 `mvn test package`，前端 `npm test`、`npm run build`。镜像构建不会跳过后端测试。

后端9个单元测试覆盖十进制、数量容量与保留款；16个HTTP/JPA集成场景覆盖完整变更验收成本结算收付闭环、独立审批、重复计量、版本冲突、角色响应隐私、部门与成员撤销、匿名/CSRF、退款冲正幂等、附件与最后管理员。

H2仅用于快速集成，不代替MySQL验收。使用独立Compose项目和全新MySQL卷启动后，实际调用健康、登录与完整业务，并验证迁移、唯一约束、权限及备份恢复。通过浏览器实际操作岗位、管理表单、打印与中英文/手机布局。README截图仅取实际运行的合成TEST资料，不是真实客户。

`scripts/smoke.py` 必须 ALLOW_TEST_DATA=1 且本机专用地址才运行，凭据不输出；不在真实数据库使用。最终执行结果只在实际完成后记入交付记录，任何未执行检查不能称通过。

验收记录（2026-10-05）：后端25项、前端2项、全新MySQL业务及权限198项、独立备份恢复15项通过；格式、静态检查、前端构建、Compose配置与两个镜像构建通过。浏览器验证登录、筛选、资金登记、手机申报、图片上传、独立验收、部门增改、中英文与审计分页；CSV下载文件中的项目编号和账务金额与页面一致；单张结算预览与浏览器打印媒体样式均验证，打印样式隐藏操作界面和其他单据。未测试实体打印机。README提供9张实际运行截图。
